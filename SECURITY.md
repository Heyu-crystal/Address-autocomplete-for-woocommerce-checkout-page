# Security policy

## Supported versions

Security fixes are made for the latest release.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/heyu-crystal/address-autocomplete-for-wp-woocommerce-checkout-page/security/advisories/new) and include the plugin version, steps to reproduce and the impact. We aim to reply within a week.

Never post a Google API key in an issue. If a key was exposed, delete or regenerate it in Google Cloud > Credentials.
